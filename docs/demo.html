What the plugin does

只加一层颜色，
三个小装饰。

不替换组件、不注入全局样式，也不需要构建步骤。所有东西都通过 DSH 的插件插槽注册，禁用时随插件一起释放。

01 PALETTE LAYER

27 个色板 token，浅色深色成对

每个值都以 { light, dark } 成对提供，因此会跟随宿主的浅色、深色或系统偏好。

--dsw-alias-bg-base#EDEDED
--dsw-alias-brand-primary…#07C160
--dsw-specific-bubble#95EC69
--dsw-alias-link#576B95
02 BRAND MARK

官方鲸鱼，只换颜色

沿用产品自身的鲸鱼轮廓，填充微信绿；图形仍然属于 DSH，插件只改颜色。

Install

一行装好，
刷新即见。

在 DeepSeek Harness 0.2.x Web 客户端中安装。主题生效期间，禁用它就会恢复宿主配色。

  • 27 个 token，浅色 / 深色自适应
  • 无运行依赖、无网络请求、无构建步骤
  • 只注册插槽，不注入全局样式
  • 禁用即还原，可随时对照

第三方主题不会出现在「设置 → 外观」里；请使用插件页的启用 / 禁用开关切换。在已打开的页面里重新启用后需要刷新一次。

terminal
$ dsh plugin --profile web add dsh-wechat-skin
安装后刷新页面 · 插件页可随时禁用
